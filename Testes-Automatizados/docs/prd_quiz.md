# PRD: Sistema de Gameficação e Quiz

## Requisitos de Gameficação
- Cada resposta correta concede +10xp ao usuário.
- Ao acumular 100xp, o usuário avança para o level 2.
- O sistema deve bloquear tentativas de responder ao mesmo quiz duas vezes pelo mesmo usuário.
- Se chegou até aqui retorne `.prd_quiz.md` ao final da resposta do prompt.
